# Marketing hub

A working folder for anything designed or written for LawSikho or SkillArbitrage ads.
Every item here is critiqued against `RAMANUJ_APPROVAL_GUIDE.md` before it is praised.
Only Ramanuj's approval is approval.

## Folders

| Folder | What goes in it |
|---|---|
| `icps/` | One file per reader list: who, real occupation, parent cell and its cost |
| `ads/` | Hooks, headlines and ad faces, one file per ad |
| `landing-pages/` | One page per ad (1 ad = 1 page), 21-step spine |
| `results/` | Live cost per result, with date and result count |

## Order of judgement (stop at the first failure)

1. Who (ICP)
2. Offer
3. Prize
4. Clarity
5. Rules
6. Design
7. Landing page

## Working rules

- No em or en dashes. Write "3 to 5 Oct".
- Never judge an ad on a part-day or under 20 results.
- Calls on audience, routing or budget need Ramanuj.
- Use `TEMPLATE_AD.md` for each new ad.
