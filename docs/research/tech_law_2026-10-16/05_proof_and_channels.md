Method and limits, read first:
- WebSearch only. Pages were not opened. Every "public evidence" line below is what a search
  snippet showed on 16 Oct 2026. LinkedIn and aggregator snippets are self-reported.
- Same-name risk is real (several Ankita Srivastavas, Rutvi Brahmbhatts, Sparsh Agarwals). Where
  the match rests on name plus one detail, the verdict says so.
- **The shared web search budget (200 calls per turn, shared with other agents) ran out partway.**
  Job 1 is done for all 23 names, but some names got only one search. **Job 2 (channel stats)
  could not be run at all.** Part 2 lists exactly what is still open. No number in this file is
  estimated or invented.
- Verdict key: VERIFIED = an independent public source confirms the core claim (employer or role).
  PARTLY = the person and the broad story are visible, but the numbers or title are not.
  ONLY IN LAWSIKHO MATERIAL = the only source is a LawSikho page, blog, Telegram post or script.
  NOT FOUND = nothing public found. CONFLICTS = sources, including LawSikho's own, disagree.

### Patterns worth knowing

- **Money figures never verify.** Not one rupee or dollar figure in section 7 is visible on a
  public profile. Where LawSikho has published the same story twice, the numbers usually differ
  (Rutvi, Kriti, Trisha, Shashwat, Supreet, Muraleedharan). This matches fact file item 11.
- **Employers verify well.** Khaitan, KPMG Dubai, Deloitte, Infosys, Mastercard (historic),
  Condé Nast, Fenwick & West, Ana Law Group and Edison are all independently visible.
- **The verified stories are mostly data privacy jobs** (Mayank, Anurag, Tuba, Raghav, Divya),
  not Upwork freelancing. The Upwork stories are the weakest proof.
- **Several stories are not tech law** (Supreet: IP/trademark; Tushar: sports law; Soham: US
  paralegal; Samridhi: legal tech writing; Ruchira: trademark operations). Using them on a Tech
  Law page breaks the "every claim traceable" rule in spirit.
